# 网络质量探测

看一条路径质量的小工具。可以在 Windows、Linux 和 Android 上用。

有两种发包方式：

- **本机**：这台手机或电脑直接向目标发包，自己计算往返时间。
- **远程节点**：手机只负责选择目标和看结果。真正发包的是你自己的一台 Linux 节点，延迟在节点上用单调时钟量好再传回来，不包含手机到节点的控制通道耗时。

目标可以是合作的 NetQuality 反射器，也可以是已经在跑的业务端口。Minecraft Java（TCP 25565）和基岩版（UDP 19132）有专门的握手。端口都能改。

数字和曲线只来自已经完成的探测。没有内置假样本，也不会在还没探完时画出 100%。

## 为什么结果要分开看

合作反射器会把探测包送回来，这时可以算「探测无应答」：发出去了，超时前没有对上序号的回显。TCP 会自己重传，所以这个数字不是网卡上的物理丢包。

普通 TCP 只看能不能连上、连接花了多久、失败了几次。它不使用自定义探测帧。

普通 UDP、DNS、基岩版如果根本没有协议应答，记为「无应答 / 未知」，不能当成已经证实的丢包。收到了包但内容不对，记为协议错误。

域名解析失败、连接被拒绝、超时、节点口令错误、协议不符，界面上会用短句分开说明。

## 本地演示

需要 Go 1.22+。桌面客户端需要 Flutter（本仓库用 3.47 开发）。Linux 桌面还需要 `clang`、`cmake`、`ninja`、`pkg-config` 和 GTK 3。

终端 1：

```bash
cd server
go build -o netquality-reflector .
./netquality-reflector
```

默认只做反射器：TCP `19090`、UDP `19091`。

终端 2：

```bash
cd client
flutter pub get
flutter run -d linux
```

来源选「本机」，目标保持 `127.0.0.1`，类型选「合作反射 TCP」或「合作反射 UDP」，点「开始探测」。延迟应是零点几毫秒这一量级。点「停止探测」后不再发包。

本机演示只能证明程序在工作。要看真实线路，把反射器装到服务器上，或者让一台节点去测你的业务端口。

## 在 App 里选节点和目标

1. 「探测来源」选「本机」或「远程节点」。
2. 远程时点「管理节点」。名称自定。地址写成 `https://你的域名:8443` 这种控制地址，不要把口令写进地址。公开节点的口令留空；私有节点把节点口令填在这一栏。它和目标回显口令不是同一个。
3. 「目标」填要测的主机、端口和类型。合作反射的默认端口是 TCP `19090`、UDP `19091`。Minecraft Java 默认 `25565`，基岩版默认 `19132`。
4. 点「开始探测」。远程任务到设定的时长后节点会自己停，也可以提前点停止。停止或断开都会让节点结束这次任务。

本机的 UDP 探测会记下这次解析出的每个地址。结果上的「发往」是当前实际在用的地址。还没有哪个地址应答时，一个超时就换下一个；已经有应答之后，要连续三次没有应答才换，中途开关 VPN 不会把还在应答的地址丢掉。地址落在 `198.18.0.0/15` 时，界面会标明这是 VPN 假地址。

节点口令保存在本机应用目录里，权限尽量收成只有自己能读，不会写进网址或日志。

## 装到自己的 Linux 服务器

步骤、公开/口令两种例子、防火墙和 HTTPS 在 [docs/server-linux.md](docs/server-linux.md)。不要把真实口令写进仓库或命令历史以外的公开地方。

只做反射，给本机或节点回显用：

```bash
cd server
go build -o netquality-reflector .
./netquality-reflector -bind 0.0.0.0 -tcp-port 19090 -udp-port 19091
```

同一台机器既回显、又替手机探测别的目标：

```bash
./netquality-reflector -mode both -bind 0.0.0.0 -tcp-port 19090 -udp-port 19091 -control-addr 127.0.0.1:8443
```

控制端口默认只听本机。放到公网前，用 HTTPS 反向代理，或加上 `-tls-cert` 和 `-tls-key`。没设置 `-node-token` 时节点是公开的，谁能连上谁就能发起有上限的探测，程序启动时会警告。设置了节点口令以后，所有创建、停止、查看和结果流都会先校验，不对就不会向目标发包。

远程节点默认不探测本机、内网、链路本地和云元数据地址。要在机房里故意测局域网时，才加 `-allow-private`。元数据地址仍然禁止。
