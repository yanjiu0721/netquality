# 网络质量探测 1.1.2

构建号 5。署名：言灸。许可：GNU Affero General Public License v3.0（AGPL-3.0-only）。

这一版还没有打 Git 标签，也还没有发布安装包。下面是准备发布的说明。

## 节点和端口

- 已有远程节点可以改名称、控制地址和口令。节点编号和当前选择保持不变。
- 修改时口令留空表示继续使用已经保存在本机的口令。界面不会把原口令填出来。填写新口令才会替换。
- 端口框标明当前探测类型的默认端口。合作反射 TCP 默认 19090，合作反射 UDP 默认 19091。
- 只有端口仍是上一种类型的默认值，或者端口是空的，切换类型才会自动更换。自己填过的端口会留下。

## 实际地址

- 本机和 1.1.2 节点都会显示这次真正连通或真正发包的 IP，并注明 IPv4 或 IPv6。
- 域名解析出的地址单独标成「解析到」，不会被说成已经使用的地址。
- 1.1.2 之前的远程节点不会在结果里带地址。界面会写「节点没有报告实际使用的地址」，不会在手机上另做一次解析来冒充。

## 选址和丢包

- 还没有任何地址应答时，用来挑选地址的失败（例如 IPv6 没有应答，随后 IPv4 成功）不计入已发送、超时和正式丢包，并单独说明回退。
- 某个地址已经应答之后，对它的超时和失败仍然计入，不会因为后来又换地址而被抹掉。
- 只有一个地址时，失败从一开始就算正式结果。
- 每一个候选都失败时，这些失败计入正式结果。不会显示 0% 成功。
- 1.1.1 的节点仍可能把第一次选址失败算进统计。要分开看，节点也需要这一版。

## 指标和停止

- 结果给出已发送、已收到、超时、比率、当前/最小/平均/中位/P95/最大延迟、抖动和用时。
- 探测无应答 = 超时 ÷（超时 + 成功）。分母只含已经写出的回显尝试。分母为 0 时显示 —，不是 0%。
- 普通 TCP 和 Minecraft Java 显示失败率，不显示丢包百分比。
- 普通 UDP、DNS、自定义 UDP 和基岩版把沉默记为无应答。UDP 没有应答不能当成已经证实的丢包。
- 延迟分布只统计成功样本。P95 用最近秩，秩 = ceil(0.95 × 次数)。抖动沿用 RFC 3550。
- 手动停止后保留曲线，并给出开始、结束、用时、目标、来源、实际地址和同一套最终指标。
- 停止时还没完成的请求不计入丢包。
- 点曲线可以钉住该时刻的延迟和比率，松手后仍然保留。再点另一点会更换。新的一次探测，或该点滚出窗口后，选择不会跳到别的点上。

应用里增加了「指标说明」和「更新历史」。更新历史只列出仓库里真实存在的标签 v1.1.1，以及这一版。
