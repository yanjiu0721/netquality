# 网络质量探测 1.1.4

版本名 `1.1.4`，构建号 `7`。署名：言灸。许可：GNU Affero General Public License v3.0（AGPL-3.0-only）。

应用标识没有改，仍是 `dev.netquality.netquality`。签名也没有改。1.1.3 以及以后的安装包沿用仓库里的同一把调试证书，新的 Android 安装包会覆盖 1.1.3，不用先卸载。安装时 Android 仍会弹出系统安装确认，这一步不能跳过。1.1.2 的证书不同，从 1.1.2 升级仍要先卸载。

Git 标签是 `v1.1.4`。

## 更新源

设置里可以选择更新源：「YanJiu Git」或「GitHub」。默认是 YanJiu Git，因为这边的网络经常解析不到 github.com。检查更新和下载安装都先用选中的源。选中的源连不上，或暂时限制了请求次数时，会自动试另一个，结果里会写明这次实际用的是哪一个。

环境变量 `NQ_UPDATE_GITHUB_API` 和 `NQ_UPDATE_GITEA_API` 仍然可以指向一份同样格式的测试响应。

1.1.2 没有自更新，升级仍要自己安装。

## 更新历史

「更新历史」会向所选更新源读取发布列表，不只看最新一条。已经发布的版本都会列出来，包括比当前安装更新的版本。草稿和不是版本号的标签不会出现。

成功同步后会在本机留一份。网络失败时用上次保存的列表；没有保存过就用安装包里的说明，并标明这份列表可能不是最新。

已经发布的 1.1.2 和 1.1.3 安装包没有这份同步。那些版本不会自己看到以后的发布说明，需要先安装包含这个功能的版本。

## 被截断的说明

表单里放不下一行的提示，末尾会显示省略号。点一下展开全文，再点一下收回。本来就能显示完的短句不用点。

## HTTP 目标

HTTP 探测的目标是完整网址，或只写主机名、IP。完整网址沿用其中的协议、端口和路径。只写主机名或 IP 时按 http，端口 80，不再单独填端口。超时默认 5000 毫秒。

本机找不到或启动不了 `netquality-reflector` 时会立刻说明原因，并建议改用远程节点，不会把这次记成全部失败。Android 安装包不包含这个程序。

## 桌面安装包文件名

规范名仍是：

- `netquality-1.1.4-linux-x64.tar.gz`
- `netquality-1.1.4-windows-x64.zip`

1.1.3 的更新器只在名字里找 `amd64` 或 `x86_64`，认不出单独的 `x64`。Linux 这一版另外放了一份内容相同的兼容名，校验和也相同：

- `netquality-1.1.4-linux-x86_64.tar.gz`（与 `linux-x64` 是同一份文件）

1.1.3 的 Linux 会选中带 `x86_64` 的那一份并自己安装，不必因为认不出 `x64` 而手动升级。Windows 桌面客户端要在 Windows 上构建。构建出来以后，除了规范名 `windows-x64`，再放一份字节相同的 `netquality-1.1.4-windows-x86_64.zip`，1.1.3 的 Windows 才会自己安装。这份文件还没放上时，Windows 仍要自己安装。从这一版起，`linux-x64` 和 `windows-x64` 会被认成当前机器的 64 位包。以前的 `amd64`、`x86_64`、`aarch64` 也仍然接受。1.1.2 没有更新器，升级仍要自己安装。

名字里带 `server` 或 `reflector` 的包继续跳过，不会被客户端下载。Android 的 `arm64-v8a`、`armeabi-v7a`、`x86_64` 本来就能对上。常见手机优先使用 arm64-v8a。

这一版已经附上的客户端文件名：

- `netquality-1.1.4-linux-x64.tar.gz`
- `netquality-1.1.4-linux-x86_64.tar.gz`（与上一份相同）
- `netquality-1.1.4-arm64-v8a.apk`
- `netquality-1.1.4-armeabi-v7a.apk`
- `netquality-1.1.4-x86_64.apk`

Linux 桌面压缩包里，`netquality-reflector` 放在客户端旁边，新装的系统才能做本机 HTTP 探测。Android 安装包不包含这个程序。Windows 桌面压缩包同样应当把 `netquality-reflector.exe` 放在 `netquality.exe` 旁边，但这一次的构建机不是 Windows，没有生成那个压缩包。
